About Family Money Planner

Family Money Planner provides free, general-purpose household budgeting calculators. It is not financial advice and is not affiliated with any bank, lender or government service. Check important financial decisions independently.

How your information is handled: calculator entries are saved in local storage in this browser so they can remain available when you return. The site does not currently send those entries to a server. Anyone using the same browser profile may be able to see saved entries, so avoid entering sensitive information on a shared device. Clearing browser site data will remove saved entries.

Calculation notes: monthly budget and savings results use the figures you enter. The debt tool estimates interest using a simplified monthly-rate calculation; actual lender calculations, daily interest, fees, payment dates and rate changes can produce different results. Do not use these estimates as a lender quote.

Advertising: this version does not currently contain paid referral links. If affiliate links are added in future, they will be clearly identified as advertising. UK affiliate disclosure guidance.

Feedback: for now, you can contact the site owner through the GitHub repository where this website is maintained. Avoid posting personal financial information publicly.
